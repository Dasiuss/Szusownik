# supabase/migrations/

Tu trafiają **migracje schematu** bazy (pliki `*.sql`), wersjonowane.

Po skonfigurowaniu integracji Supabase ↔ GitHub w kroku 2 migracje będą
aplikowane automatycznie przy pushu na `main`.

Schemat bazy jest do zaprojektowania w kroku 2; założenia integracji opisuje
`docs/supabase.md`.
